# Changelog

All notable changes to the BuildFeed plugin will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-15

### Added
- Initial marketplace release
- Three curated field guides (Startups, Product, Design)
- Seven specialized agent skills
- Public MCP server integration (https://buildfeed.tech/api/mcp)
- Eight MCP tools for searching and browsing transcripts
- Comprehensive README with installation instructions and examples
- MIT License
- Plugin manifests for Cursor and Grok Bot marketplaces

### Features
- Pre-compiled knowledge bases covering common questions
- Real-time transcript search with timestamp precision
- Attribution with direct video links (YouTube ?t= timestamps)
- Read-only operation (no side effects)
- Works without authentication (optional API key for higher limits)
- Automatic routing between field guides and live library

### Supported Platforms
- Grok Bot
- Cursor AI
